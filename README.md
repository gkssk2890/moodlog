# Moodlog — 감각 기록

예쁜 것을 보면, **왜** 예쁜지 적어두는 모바일 무드보드.

- 사진·캡처를 올리면 대표 색 5개를 자동으로 뽑고, 사진을 탭하면 그 지점의 색을 담아요
- 폰트 · 간격/레이아웃 · 출처를 메모하고, "왜 예뻐 보였는지"를 글과 키워드(대비, 여백, 위계…)로 남겨요
- 기록 하나를 **카드 이미지**로, 보드 전체를 **콜라주 이미지** 또는 **보드 파일(.json)** 로 공유해요
- 친구가 보낸 보드 파일은 [받은 보드]에서 열어 이유까지 읽고, 마음에 드는 기록은 내 보드에 담을 수 있어요
- [나] 탭에서 내가 자주 꼽는 이유, 컬러 취향, 백업/복원을 볼 수 있어요

기록은 서버 없이 각자 폰의 브라우저(IndexedDB)에 저장됩니다.

## 설치
- iPhone: Safari로 열고 공유 → 홈 화면에 추가
- Android: Chrome 메뉴(⋮) → 앱 설치

## 배포
정적 파일만으로 동작합니다. GitHub Pages (main 브랜치 / root)로 배포돼요.
